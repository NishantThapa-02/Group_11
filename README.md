# Group_11
Members (Asim Lamsal, Melanie Garza, Nishant Thapa, Savion Mychal Judge Watson, Ujjwal Dhungana)

This program utilizes parallel arrays to create a grocery management system that a user can manipulate based on menu selection. The menu has the options of either view stock, add stock, or exit. 

Main.java: Creates parallel arrays, prompts user for menu selection and calls the below methods.
Inventory.java: Handles displaying entire grocery store stock, skipping empty items.
Restock.java: Takes user input to search inventory for item, and adds stock to that item.
